# `UniformProbabilityDistributionSamplerValidation`

Immutable `ValidationResult` containing `sample_count`, `support_is_valid`,
`mean_absolute_error`, `mean_acceptance_limit`, `variance_absolute_error`,
`variance_acceptance_limit`, `maximum_bin_count_deviation`, and
`bin_count_acceptance_limit`. `is_valid` requires every criterion to pass.
