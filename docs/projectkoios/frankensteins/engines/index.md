# `projectkoios.frankensteins.engines`

**Source:** `src/projectkoios/frankensteins/engines/`

This implicit package owns immutable source-qualified historical engine identities.

- [`BaseEngine`](base/index.md) is the shared nominal identity contract.
- [`pyflamestk_examples`](pyflamestk_examples/index.md) catalogs 17 exact PyFlamestk example trees.
- [`pypospack_examples`](pypospack_examples/index.md) catalogs 31 exact PyPosPack example trees.
- [`pyflamestk_lmps_mgo_serial_uniform`](pyflamestk_lmps_mgo_serial_uniform/index.md) retains its exact source constants and maintained charge-distribution declaration.

Callers import from the defining leaf module. Static engine bindings do not authorize source inspection, reconstruction, or execution.
