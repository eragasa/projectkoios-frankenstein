# `pyflamestk_lmps_mgo_serial_uniform.constants`

**Source:** `.../pyflamestk_lmps_mgo_serial_uniform/constants.py`

This module binds the engine to an externally hosted source revision.

| Constant | Role |
|---|---|
| `SOURCE_COMPONENT` | `pyflamestk` |
| `SOURCE_REPOSITORY_URL` | `https://github.com/eragasa/pyflamestk` |
| `SOURCE_REVISION` | Exact Git commit |
| `SOURCE_TREE` | Exact Git tree object |
| `SOURCE_LICENSE_PATH` | Repository-relative license path |
| `SOURCE_LICENSE_SHA256` | Exact license digest |
| `EXAMPLE_ROOT` | Selected MgO example root |
| `ENGINE_NAME` | Stable engine name |
| `SOURCE_FILES` | Explicit path-to-(SHA-256, byte-size) identity table |

These constants are identities, not discovery hints. The engine never searches
for alternate repositories, revisions, examples, or files.
