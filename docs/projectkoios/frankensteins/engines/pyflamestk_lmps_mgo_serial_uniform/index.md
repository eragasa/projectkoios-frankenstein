# `projectkoios.frankensteins.engines.pyflamestk_lmps_mgo_serial_uniform`

**Source:** `src/projectkoios/frankensteins/engines/pyflamestk_lmps_mgo_serial_uniform/`

This implicit package retains the maintained pieces of the PyFlamestk MgO serial-uniform incubation:

- [`constants`](constants/index.md) owns exact external-source identities.
- [`charge_distribution`](charge_distribution/index.md) constructs the declared magnesium-charge distribution.

Implementations are imported from their defining modules rather than from a package façade. The package does not import or execute upstream PyFlamestk code.
