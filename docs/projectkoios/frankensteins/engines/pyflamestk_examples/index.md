# `projectkoios.frankensteins.engines.pyflamestk_examples`

This implicit package owns the bounded PyFlamestk example-engine catalog. [`bindings`](bindings/index.md) declares exact source-tree identities, reconstruction dispositions, aliases, and root-level historical entrypoints.

The catalog is immutable metadata. It does not inspect a checkout, reconstruct a workflow, import historical Python, or execute an entrypoint.
