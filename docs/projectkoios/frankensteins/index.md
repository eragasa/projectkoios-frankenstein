# `projectkoios.frankensteins`

**Source:** `src/projectkoios/frankensteins/`

This implicit incubation namespace owns maintained, provenance-conscious reconstructions and calculator-neutral scientific workflow components. Implementations remain in their owning leaf modules and are not broadly re-exported.

## Maintained packages

- [`adapters`](adapters/index.md) owns binding and integration roles.
- [`applications`](applications/index.md) owns calculator-neutral workflows.
- [`engines`](engines/index.md) owns bounded historical engine identities.
- [`integrations`](integrations/index.md) owns external-application formats and behavior.
- [`io`](io/index.md) owns remaining maintained input representations.
- [`mathematics`](mathematics/index.md) owns probability contracts.
- [`physkit`](physkit/index.md) owns PhysKit-shaped extraction candidates.
- [`simulations`](simulations/index.md) owns calculator-neutral simulation records.
- [`validation`](validation/index.md) owns validation contracts.

## Safety boundary

The package does not grant calculator execution authority, discover or fetch upstream repositories, execute retained historical source, or imply numerical verification or scientific validation.
