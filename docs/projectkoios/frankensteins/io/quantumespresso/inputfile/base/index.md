# `base`

Nominal immutable Quantum ESPRESSO input groups.

`QeCard` is the shared base for `QeControlCard`, `QeSystemCard`, `QeElectronsCard`, `QeIonsCard`, `QeCellCard`, `QeFcpCard`, `QeRismCard`, `QeAtomicSpeciesCard`, `QeAtomicPositionsCard`, `QeKpointsCard`, `QeAdditionalKpointsCard`, `QeCellParametersCard`, `QeOccupationsCard`, `QeConstraintsCard`, `QeAtomicVelocitiesCard`, `QeAtomicForcesCard`, `QeSolventsCard`, and `QeHubbardCard`.
