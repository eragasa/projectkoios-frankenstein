# `projectkoios.frankensteins.io.vasp`

Maintained VASP text-I/O records and transformations. Implementations remain in their owning modules rather than being broadly re-exported from this package.

- [`incar`](incar/index.md) owns generic INCAR parsing and writing.
- [`poscar`](poscar/index.md) writes the shared unit-cell model as POSCAR.
