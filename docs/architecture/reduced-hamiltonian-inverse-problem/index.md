# Reduced-Hamiltonian inverse problem

**Status:** Target adaptation for `ksdft2effmass`; no production silicon fit is
claimed or authorized here.

This module adapts the reconstructed PyPosPack/PyFlamestk pattern to the
bulk-silicon question defined by the `ksdft2effmass` conference and manuscript
program. The optimized object is an immutable parameterized tight-binding
Hamiltonian, not an interatomic potential.

The exact target evidence inspected for this architecture is recorded in the
[`ksdft2effmass` bulk-silicon target reference](../../references/ksdft2effmass-bulk-silicon-target.md).
