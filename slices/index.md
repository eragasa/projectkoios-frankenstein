# Frankenstein implementation slices

A slice is one end-to-end, independently reviewable outcome. Plans order slices; slices consume module-owned tasks and subtasks; tasks retain implementation ownership.

- [Bulk-silicon QE slices](bulk-silicon-qe/index.md)

A slice does not own reusable integration behavior. It links the exact task outputs it consumes and defines its demonstration, evidence, and acceptance boundary.
