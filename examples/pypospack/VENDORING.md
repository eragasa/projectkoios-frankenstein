# pypospack example-code vendoring

492 code files were copied from the pinned upstream examples tree.

`PROVENANCE.json` records the repository, pinned revision and tree, selection rules, original path, Git mode, Git blob identity, SHA-256 digest, and byte size for every copied code file. The upstream `LICENSE` is preserved alongside it.

The code is historical upstream material and is not imported by the maintained package. No claim of numerical verification or scientific validation is made.

`MgO/buck/` is a separately bounded maintained representation. Its own `PROVENANCE.json` identifies the exact configuration, structures, sampler implementation, and QOI runtime selected from the pinned source, as well as locally authored or modified files. `VENDORING.toml` drives reproducible extraction and provenance refresh through `tools/vendor_source_selection.py`.
