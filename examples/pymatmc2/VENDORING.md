# pymatmc2 example-code vendoring

The pinned revision has no upstream examples/ tree, so no code files were copied.

`PROVENANCE.json` records the repository, pinned revision and tree, selection rules, original path, Git mode, Git blob identity, SHA-256 digest, and byte size for every copied code file. The upstream `LICENSE` is preserved alongside it.

The code is historical upstream material and is not imported by the maintained package. No claim of execution readiness, numerical verification, or scientific validation is made.
